# Employee Welfare Management and Personalized Recommendation System

A K-Means clustering–based system to personalize employee welfare recommendations
for Kenyan organizations, using Next.js, ASP.NET Core, PostgreSQL, and scikit-learn.

## Structure
- `/frontend` — Next.js web app
- `/backend` — ASP.NET Core Web API
- `/ml-service` — Python clustering service
